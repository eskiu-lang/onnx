## `<onnx>`

ONNX model inference over ONNX Runtime (`<onnx>`).

onnx_session() loads a model; OnnxSession_run() feeds it tensors by input name
and returns the outputs. Every fallible call returns a Result whose error is a
message from ONNX Runtime or from the checks here; the message lives in a buffer
that the next error reuses, so copy it to keep it. Sessions and tensors have a
release method, meant to be paired with defer:

```eskiu
OnnxSession s = onnx_session("model.onnx", null)?;
defer s.release();
int64[2] shape = {1, 4};
OnnxTensor x = onnx_tensor_f32(&data[0], &shape[0], 2)?;
defer x.release();
OnnxTensor y = s.run1(&x)?;
defer y.release();
*float out = y.f32();
```

The whole C API is in `<onnx/raw>` for anything this layer does not cover.

## `<onnx/detect>`

Post-processing for detection models (`<onnx/detect>`).

An SSD-style detector gives, for each of its anchors (prior boxes), a box encoded
relative to the anchor and class scores. These functions make the anchors from the
model's configuration, decode the boxes, keep the scores above a threshold and drop
overlapping boxes with greedy non-maximum suppression, in float32 with the same
operations, in the same order, as the numpy and PyTorch code such models ship with,
so the boxes come out bit for bit the same.

```eskiu
List<OnnxAnchor> anchors;
onnx_anchors_grid(&anchors, 40, 40, 16.0, 640.0, 640.0, &ws[0], &hs[0], 2);
OnnxBoxCoder coder = onnx_coder_variance(0.1, 0.2);
onnx_boxes_decode(loc.f32(), anchors.data, anchors.size, &coder, boxes);
List<int> found;
onnx_scores_above(conf.f32() + 1, anchors.size, 2, 0.5, &found);
List<int> keep;
onnx_nms(boxes, conf.f32() + 1, 2, found.data, found.size, 0.4, &keep);
```

### OnnxAnchor

```eskiu
struct OnnxAnchor {
    float cx;
    float cy;
    float w;
    float h;
}
```

An anchor by its center and size, in the units of the encodings (usually fractions

### OnnxBox

```eskiu
struct OnnxBox {
    float x1;
    float y1;
    float x2;
    float y2;
}
```

A box by its corners.

### onnx_linspace

```eskiu
void onnx_linspace(*double out, double start, double stop, int n)
```

n values from start to stop, as numpy.linspace(start, stop, n): i * step + start with
step = (stop - start) / (n - 1), the last one stop itself.

### onnx_anchors_grid

```eskiu
void onnx_anchors_grid(List<OnnxAnchor>* out, int rows, int cols, double step, double size_x, double size_y, *double widths, *double heights, int n)
```

Appends the anchors of one feature map of rows x cols cells: row by row, column by
column, and in each cell one anchor per shape, widths[s] by heights[s], centered at
((column + 0.5) * step / size_x, (row + 0.5) * step / size_y). Computed in double and
stored as float, as Python code that builds a list and converts it to float32.
RetinaFace-style priors take the layer's stride as step and the input size as
size_x and size_y; TensorFlow-style anchors in 0..1 take step 1 and size cols, rows.

### onnx_anchors_clip

```eskiu
void onnx_anchors_clip(*OnnxAnchor a, int n)
```

Clamps every value of n anchors into 0..1 (PriorBox's clip).

### OnnxBoxCoder

```eskiu
struct OnnxBoxCoder {
    bool yx;
    bool variance;
    float center = 10.0;
    float size = 5.0;
}
```

How a box is encoded against its anchor. With variance unset (TensorFlow's
FasterRcnnBoxCoder, used by its SSDs): cx = tx / center * aw + acx, w = exp(tw / size)
* aw, and the corners are cx -+ w / 2. With variance set (SSD and RetinaFace in
PyTorch): cx = acx + tx * center * aw, w = aw * exp(tw * size), x1 = cx - w / 2 and
x2 = w + x1. yx says the encoding is (ty, tx, th, tw), TensorFlow's order, rather
than (tx, ty, tw, th).

### onnx_coder_tf

```eskiu
OnnxBoxCoder onnx_coder_tf()
```

TensorFlow's SSD encoding: (ty, tx, th, tw) with scale factors 10, 10, 5, 5.

### onnx_coder_variance

```eskiu
OnnxBoxCoder onnx_coder_variance(float center, float size)
```

The PyTorch SSD and RetinaFace encoding with these variances (usually 0.1, 0.2).

### onnx_boxes_decode

```eskiu
void onnx_boxes_decode(*float enc, *OnnxAnchor anchors, int n, *OnnxBoxCoder coder, *OnnxBox out)
```

Decodes n boxes, four floats each in enc, against their anchors, into out (x1, y1,
x2, y2 in the anchors' units). Each step is one float32 operation, as numpy and
PyTorch evaluate the formulas; exp is the C library's expf.

### onnx_boxes_clamp

```eskiu
void onnx_boxes_clamp(*OnnxBox b, int n, float w, float h)
```

Clamps n boxes into 0..w and 0..h (1, 1 for fractions of the input, as np.clip(boxes,
0, 1)). A NaN stays NaN, as in numpy.

### onnx_scores_above

```eskiu
void onnx_scores_above(*float scores, int n, int stride, float threshold, List<int>* out)
```

Appends to out each i in 0..n whose score scores[i * stride] is at least threshold,
in order (np.flatnonzero(scores >= threshold)). With a [N, classes] score tensor,
pass the class's column (scores + k) and stride classes.

### onnx_box_iou

```eskiu
float onnx_box_iou(OnnxBox a, OnnxBox b)
```

The intersection over union of two boxes, 0 when the union is empty, computed as
onnx_nms does.

### onnx_nms

```eskiu
void onnx_nms(*OnnxBox boxes, *float scores, int stride, *int candidates, int n, float iou, List<int>* keep)
```

Greedy non-maximum suppression: among the n candidates (indices into boxes and
scores, scores[i * stride] being box i's score; null for 0..n-1), the best scoring
box is kept and every remaining one that overlaps it by more than iou (intersection
over union, as onnx_box_iou) is dropped, until none is left. Appends the kept
indices to keep, best first. The order is np.argsort(scores, kind="stable")[::-1]:
equal scores keep the later candidate first, and a NaN score comes first. numpy's
default argsort gives the same order when no two scores are equal (and, being an
insertion sort there, for up to 16 candidates).


## `<onnx/image>`

Image preprocessing for vision models (`<onnx/image>`).

The functions here work on 8-bit RGBA pixels, four bytes per pixel, rows packed
with the top row first: what `<gpu/image>`'s image_load returns for PNG and JPEG
files, and what most decoders and cameras give. The buffers they return come
from alloc and go back with free.

```eskiu
*uint8 face = onnx_image_crop(img.rgba, w, h, x, y, size, size, ONNX_BORDER_REFLECT);
*uint8 small = onnx_image_resize(face, size, size, 128, 128);
OnnxImageFormat f = onnx_format_unit();
OnnxTensor t = onnx_image_tensor(small, 128, 128, &f)?;
```

### ONNX_BORDER_ZERO, ONNX_BORDER_CLAMP, ONNX_BORDER_REFLECT

```eskiu
const int ONNX_BORDER_ZERO = 0;
const int ONNX_BORDER_CLAMP = 1;
const int ONNX_BORDER_REFLECT = 2;
```

What onnx_image_crop puts outside the image.

### OnnxImageFormat

```eskiu
struct OnnxImageFormat {
    bool nhwc;
    bool bgr;
    float scale = 1.0;
    float[3] mean;
    float[3] std;
}
```

How pixels become tensor values: value = (pixel * scale - mean[c]) / std[c],
with c the channel in the tensor's order (B, G, R when bgr is set) and a zero
std taken as 1. Layout NCHW ([1, 3, h, w]) unless nhwc is set ([1, h, w, 3]).
The zero value with its default scale gives 0..255 RGB in NCHW.

### onnx_image_resize

```eskiu
*uint8 onnx_image_resize(*uint8 rgba, int w, int h, int nw, int nh)
```

Resizes to nw x nh with bilinear filtering and half-pixel centers (as ONNX

### onnx_image_resize_pillow

```eskiu
*uint8 onnx_image_resize_pillow(*uint8 rgba, int w, int h, int nw, int nh, int filter)
```

Resizes to nw x nh as Pillow's Image.resize does, byte for byte: filter is
ONNX_PILLOW_BILINEAR, _BICUBIC, _LANCZOS, _BOX or _HAMMING, with Pillow's support
scaling when shrinking, its 22-bit fixed-point weights and the clip to 8 bits
between the horizontal and the vertical pass. Pillow 11 and 12 always run the
horizontal pass first; Pillow 13 runs the vertical one first when the height
shrinks by more than twice as many pixels as the width, which ONNX_PILLOW_13 in
filter selects. The four channels are resampled alike, as Pillow resizes an RGB
image; for RGBA with transparency Pillow premultiplies the alpha first, which this
does not. (After the BILINEAR resampler of the face-pasive-liveness service's
native/image.esk.)

### onnx_image_crop_pillow

### onnx_image_resize_cv2

```eskiu
*uint8 onnx_image_resize_cv2(*uint8 rgba, int w, int h, int nw, int nh)
```

Resizes to nw x nh as OpenCV's cv2.resize with INTER_LINEAR (the default) does on
8-bit images, byte for byte: the half-pixel sample positions in float, 11-bit
weights, the exact horizontal pass and OpenCV's vertical rounding
((((h0 >> 4) * b0) >> 16) + (((h1 >> 4) * b1) >> 16) + 2) >> 2. That is OpenCV's own
code, which every build runs except where a CPU-specific library takes over: arm64
builds with KleidiCV (the opencv-python 5.0 wheel for macOS arm64) shrink both
sides of an image with up to 3 channels by 1 to 3 times with an approximation that
differs by a level, and Carotene (arm builds) resizes 1 and 4 channel images
itself. Each channel is computed alike, so the RGB of an RGBA image matches
cv2.resize of the 3-channel image.

### OnnxRect

```eskiu
struct OnnxRect {
    int x1;
    int y1;
    int x2;
    int y2;
}
```

A box by its corner pixels, both included.

### onnx_minifasnet_box

```eskiu
OnnxRect onnx_minifasnet_box(int src_w, int src_h, double x, double y, double w, double h, double scale)
```

The crop of Minivision's Silent-Face-Anti-Spoofing (CropImage._get_new_box) for a
face box (x, y, w, h) in a src_w x src_h image: the box scaled by scale about its
center (MiniFASNet uses 2.7 and 4.0), the scale first lowered so the crop fits in
(src_w - 1) x (src_h - 1), and a crop that leaves the image shifted inward rather
than cut. Corners truncated toward zero as Python's int(). An empty rect
(x2 < x1) when w or h is not positive.

### onnx_minifasnet_crop

```eskiu
*uint8 onnx_minifasnet_crop(*uint8 rgba, int w, int h, double x, double y, double bw, double bh, double scale, int out_w, int out_h)
```

MiniFASNet's input patch: the onnx_minifasnet_box crop (corners included, as
img[y1:y2 + 1, x1:x2 + 1]) resized to out_w x out_h with onnx_image_resize_cv2, as
the upstream CropImage.crop does with cv2.resize. The model then takes it as BGR
floats in 0..255 (OnnxImageFormat{bgr: true}). null when the box is empty.
